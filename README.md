# 🏗️ PIC ERP Backend (Construction ERP System)

A modular, role-based ERP backend built with **Django + DRF**, designed for construction and infrastructure companies operating in the **UAE** and **KSA**.

This system manages **companies, departments, employees, roles, permissions, and approval hierarchies** with clear Role-Based Access Control (RBAC).

---

## ⚙️ Tech Stack

- **Backend:** Django REST Framework  
- **Auth:** JWT (via `SimpleJWT`)  
- **Database:** SQLite / PostgreSQL  
- **Architecture:** Modular RBAC with Department & Company context  
- **API Testing:** Postman Collection (included)
